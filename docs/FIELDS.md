# 输出字段

| 字段 | 含义 |
| --- | --- |
| 职位ID / 职位链接 | 从可见卡片的详情链接中取得；去掉查询参数与锚点，按 ID 去重 |
| 岗位名称 / 公司名称 | 卡片可见原文；公司不存在时留空 |
| 薪资原文 | 不换算年包、税前税后或月数，避免推断错误 |
| 城市区域 | 卡片显示的地址片段，不做地理编码 |
| 经验 / 学历 | 从卡片要求标签按关键词提取首个匹配项，可能留空；不是智能推断 |
| 卡片要求原文 | 保留全部已识别要求标签，使用 ` | ` 分隔，以便核对提取结果 |
| 技能标签 / 公司标签 / 福利原文 | 页面对应字段，不存在就留空；不承诺分拆公司融资与规模 |
| 详情页岗位名称 | 详情页标题，用来辅助核对卡片与 JD |
| 职位描述JD / 工作地址 | 只读取正常打开详情页中匹配到的可见内容，不猜测隐藏字段 |
| JD状态 / JD备注 | `pending` / `ok` / `unavailable` / `no_visible_jd`，详见 README |
| 卡片原文 | 卡片整体可见文字，用于字段缺失时回看，不含图片或未渲染内容 |
| 推荐来源页 | 手动确认的推荐页地址；本地数据可能包含该地址的查询参数，不公开 |
| 首次采集时间UTC / 更新时间UTC | ISO 8601 UTC 时间，`+00:00`；更新时间是本地记录更新时间，并非职位发布时间 |

CSV/XLSX 使用中文列名，SQLite 的 JSON 使用英文键。列表去重保留首次出现的卡片；JD 完成后不会每次重新抓取。薪资、标签和排序均为当次页面快照。

`pending` 不代表 JD 一定可访问；`ok` 也不代表字段经过人工校验。详情正文可能因页面变化提取不全，首次使用必须核对少量样本。
